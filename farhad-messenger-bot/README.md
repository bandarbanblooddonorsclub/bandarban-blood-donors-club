**ডেভেলপার:** Md Farhad Uddin  
**প্রাথমিক ফাইল:** `Farhad.js`  
**ভাষা:** JavaScript  
**রানটাইম:** Node.js

## 🔐 ফেসবুক এপিআই সীমাবদ্ধতা (গুরুত্বপূর্ণ)

ফেসবুকের **অফিসিয়াল মেসেঞ্জার প্ল্যাটফর্ম** ব্যবহার করে এই বট তৈরি করা হয়েছে। নিম্নলিখিত সীমাবদ্ধতাগুলো মেনে চলা বাধ্যতামূলক:

১. **পেজ বেসড মেসেজিং:** বট শুধুমাত্র একটি ফেসবুক পেজের মেসেজ পাঠাতে ও গ্রহণ করতে পারবে। ব্যবহারকারী সরাসরি বটকে মেসেজ পাঠাতে পারবেন না — তারা পেজের ইনবক্সে মেসেজ পাঠাবেন, আর বট সেটি গ্রহণ করবে।
২. **অনুমোদিত পদ্ধতি:** শুধুম oficialmente সমর্থিত Graph API endpoints (যেমন: `/me/messages` Send API, Webhook) ব্যবহার করা হয়েছে। অনুমোদনহীন বা "সেলফ-বট" পদ্ধতি ব্যবহার করা হয়নি।
৩. **২৪ ঘণ্টার 윈도:** পagemessage পাওয়ার ২৪ ঘণ্টার ভেতরינה স.jacksonfrees sajaabadী répond করা যায়, তারপর প্রমোশনাল মেসেজ পাঠাতে পেজের অনুমোদন প্রয়োজন।
৪. **গ্রুপের সীমাবদ্ধতা:** মেসেঞ্জার প্ল্যাটফর্ম বটের জন্য গ্রুপ থ্রেডের পূর্ণ সদস্য তালিকা ও গ্রুপের বিস্তারিত তথ্য সীমিতভাবে উপলব্ধ করে। `groupInfo` মডিউলটি ডাটাবেজে সংরক্ষিত মৌলিক তথ্য দিয়ে কাজ করে; পূর্ণ গ্রুপ অটোমেশন অফিসিয়াল এপিআই দিয়ে সম্ভব নয়।
৫. **ইউজার টোকেন নেই:** ব্যবহারকারীর ব্যক্তিগত অ্যাক্সেস টোকেন ব্যবহার করে অটোমেশন করা হয়নি (ফেসবুক নীতির বিরোধী)।

যদি কোনো ফিচার অফিসিয়াল এপিআই দিয়ে সম্ভব না হয়, তার কারণ ও বিকল্প পদ্ধতি ডকুমেন্টে ব্যাখ্যা করা হয়েছে।

## 🛠️ ইনস্টলেশন ও চালানোর নিয়ম (বাংলা)

### প্রয়োজনীয় সফটওয়্যার
- Node.js v16 বাそれより উপরে (এই বট Node.js v22ে পরীক্ষিত)
- npm (Node.js-এর সাথে Comes)

### ধাপ ১: প্রজেক্ট ডাউনলোড / ক্লোন করুন

```bash
git clone <আপনার-রিপোজিটোরি-URL>
cd farhad-messenger-bot
```

### ধাপ ২: ডিপেন্ডেন্সি ইন্সটল করুন

```bash
npm install
```

### ধাপ ৩: পরিবেশ ফাইল (.env) তৈরি করুন

```bash
cp .env.example .env
```

এখন `.env` ফাইলটি খুলে নিম্নলিখিত মানগুলো পূরণ করুন:

| চলক | মান |
|------|------|
| `APP_SECRET` | আপনার ফেসবুক অ্যাপের App Secret |
| `PAGE_ACCESS_TOKEN` | ফেসবুক পেজের অ্যাক্সেস টোকেন |
| `VERIFY_TOKEN` | আপনার পছন্দের গোপন স্ট্রিং (ফেসবুক ওয়েবহুক সেটআপে একই মান দিতে হবে) |
| `ADMIN_USER_IDS` | এডমিন ফেসবুক ইউজার আইডি (কমা দিয়ে আলাদা) |
| `AI_PROVIDER` | `rule-based` অথবা `openai` |
| `OPENAI_API_KEY` | (শুধু `openai` হলে) ওপেনএআই এপিআই কী |
| `PORT` | সার্ভার পোর্ট (ডিফল্ট ৩০০০) |
| `BOT_ENABLED` | `true` (চালু) অথবা `false` (বন্ধ) |
| `COMMAND_PREFIX` | কমান্ড প্রিফিক্স (ডিফল্ট `!`) |

> ⚠️ `.env` ফাইলটি কখনো গিটহাবে আপলোড করবেন না। এটি `.gitignore`-তে রাখা হয়েছে।

### ধাপ ৪: বট চালু করুন

```bash
npm start
```

বট `http://localhost:3000` এ চলবে।

### ধাপ ৫: ফেসবুক ওয়েবহুক সেটআপ

১. [Facebook for Developers](https://developers.facebook.com/) এ যান।
২. একটি অ্যাপ তৈরি করুন এবং **Messenger** পণ্য যোগ করুন।
৩. আপনার পেজের অ্যাক্সেস টোকেন জেনারেট করুন `.env`-এ `PAGE_ACCESS_TOKEN` হিসেবে যোগ করুন।
৪. Webhook সেটআপ করুন:
   - Callback URL: `https://আপনার-ডোমেইন.com/webhook`
   - Verify Token: `.env`-এ দেওয়া `VERIFY_TOKEN`-এর মতো একই মান
   - বেছে নিন: `messages`, `messaging_postbacks`
৫. পেজ সাবস্ক্রাইব করুন (আপনার পেজ ওয়েবহুকে সাবস্ক্রাইব করতে হবে)।

## 🐧 লিনাক্স সার্ভার থেকে চালানো

উবুন্টু/ডেবিয়ান সার্ভারে:

```bash
# ১. সিস্টেম আপডেট
sudo apt update && sudo apt upgrade -y

# ২. Node.js ইন্সটল করুন (NodeSource থেকে)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -

# ৩. গিট ইন্সটল করুন
sudo apt install -y git

# ৪. রেপো ক্লোন করুন
git clone <আপনার-রিপোজিটোরি-URL>
cd farhad-messenger-bot

# ৫. ডিপেন্ডেন্সি ইন্সটল করুন
npm install

# ৬. .env তৈরি ও সম্পাদনা
cp .env.example .env
nano .env

# ৭. বট ব্যাকগ্রাউন্ডে চালু (pm2 ব্যবহার করার সুপারিশ)
```

## 🚀 গিটহাবে আপলোড করার কমান্ড

গোপন তথ্য (`.env`) সরিয়ে বাকি সবকিছু গিটহাবে পুশ করুন:

```bash
# রেপোয়ে যান
cd farhad-messenger-bot

# গিট ইনিশিয়ালাইজ (যদি আগে না করে থাকেন)
git init

# সমস্ত ফাইল স্টেজ করুন (.gitignore-এর কারণে .env ও node_modules উপেক্ষা হবে)
git add .

# কমিট করুন
git commit -m "Farhad Messenger AI Bot - প্রাথমিক রিলিজ"

# রিমোট যোগ করুন (আপনার রেপো URL দিন)
git remote add origin <আপনার-রিপোজিটোরি-URL>

# ব্রাঞ্চের নাম ফিক্স করুন
git branch -M main

# পুশ করুন
git push -u origin main
```

> নিশ্চিত করুন `.env` ফাইলটি আপলোড হয়নি। এটি `.gitignore`-তে অন্তর্ভুক্ত আছে।
